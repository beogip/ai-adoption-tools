# Security Policy

## Scope

This is a fully client-side static site. There is no backend, no API, and no user data leaves the browser (state is stored in `localStorage` only).

## Supported Versions

Only the latest deployed version is supported.

## Reporting a Vulnerability

Please do not open a public issue for security reports. Use [GitHub Private Vulnerability Reporting](https://github.com/beogip/ai-adoption-tools/security/advisories/new) instead.

You can expect a response within 5 business days.
